## Idioma del proyecto

Todo el contenido, documentación, comentarios y textos de este proyecto deben estar en español. Nada en inglés (salvo la sintaxis propia del lenguaje/framework: etiquetas HTML, palabras clave de JS/Astro, nombres de paquetes npm, clases de Tailwind, etc.).

## Desarrollo

Al iniciar el servidor de desarrollo, usa el modo en segundo plano:

```
astro dev --background
```

Administra el servidor en segundo plano con `astro dev stop`, `astro dev status` y `astro dev logs`.
